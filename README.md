# Forvilla — Vendor Uploads & Social Content for 10 Handmade Market Events

Complete deliverable for the assignment:
**(1)** upload-ready vendor lists for 10 upcoming handmade market events,
**(2)** automated data quality and consistent formatting, and
**(3)** the data converted into social media posts in Forvilla's voice.

> **Note on the data:** no source vendor spreadsheets were provided with the assignment, so
> `data/raw/` contains **realistic simulated intake files** (generated by
> `scripts/00_make_sample_raw.py`) reproducing how organizer spreadsheets actually arrive —
> mixed date/phone formats, free-text categories, Instagram URLs vs handles, duplicates,
> missing contacts. To run this on real data, drop the real files into `data/raw/` in the
> same column layout and skip step 00.

## How to run

```bash
python3 scripts/00_make_sample_raw.py   # only for the demo data — skip with real files
python3 scripts/01_clean.py             # raw -> clean, upload-ready CSVs
python3 scripts/02_validate.py          # writes reports/data_quality_report.md, exits 1 on errors
python3 scripts/03_generate_posts.py    # clean data -> 30 posts + content calendar
```

No dependencies beyond the Python 3 standard library.

## What the cleaning step guarantees (`01_clean.py`)

- **Names/venues/cities** → Title Case; **dates** → ISO `YYYY-MM-DD`; **times** → `H:MM AM/PM`
- **Categories** → mapped from free text onto the controlled 14-value taxonomy
  (unknown categories abort the run rather than slipping through)
- **Phones** → `(XXX) XXX-XXXX` · **emails** → lowercase, validated ·
  **Instagram** → `@handle` (URLs stripped) · **booths** → `A1` style
- **Duplicates** within an event dropped and logged (2 caught in the sample data)
- **Stable vendor IDs** (`FV-001`…): the same artisan gets the same ID, name, and contact
  info in every event file; a contact missing from one intake file is backfilled from the
  vendor's other event rows

## What validation proves (`02_validate.py`)

An independent re-check (not the cleaner grading its own work): field-format regexes,
taxonomy membership, duplicate vendors/booths, cross-file consistency, referential
integrity vendor→event, ≥5 vendors per event, no past-dated events. Result for this run:
**PASS — 10 events, 80 vendor rows, 35 unique vendors, 0 errors**, 2 warnings (one vendor
has no Instagram on file → follow-up list). Exits non-zero on errors so it can gate uploads.

## Social content (`03_generate_posts.py`)

Per event, in Forvilla's voice ("villagers", "come out for the village", maker-story focus):

1. **Instagram announcement** (T-7 days) — full vendor lineup with category emoji and handles
2. **Instagram vendor spotlight** (T-3 days) — rotating featured artisan, their booth and products
3. **Facebook event post** (T-1 day) — lineup grouped by category, app features call-out

Every fact in every post (names, handles, booths, dates, venues) is pulled from the cleaned
data — regenerating after a data fix updates all 30 posts automatically.
